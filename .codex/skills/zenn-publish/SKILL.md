---
name: zenn-publish
description: 設定済みの Zenn API 連携で記事を公開または更新するときに使う。記事の執筆・ローカル検証だけには使わない。
---

## 公開前の確認

- ユーザーが公開または更新を明示的に依頼していることを確認する。曖昧な「投稿できるようにして」は API を実行する許可ではない。
- 対象の記事、公開か下書きか、変更内容を確認する。
- `zenn-blogger` の完了条件と `npm run lint` を満たすことを確認する。
- 利用可能な Zenn API 連携、認証方法、エンドポイント、ペイロードを既存設定または公式ドキュメントで確認する。値を推測・補完しない。

## 実行と報告

- 確認済みの連携だけを使い、対象外の記事を変更しない。
- API のレスポンスから公開結果と記事 URL または識別子を確認する。
- 実行した対象、公開状態、結果を簡潔に報告する。設定不足や認証失敗時は、公開済みと扱わない。
