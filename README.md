# zenn-blogs

Zennで公開している技術記事のリポジトリです。

Codex での執筆ルールは [AGENTS.md](AGENTS.md) に、記事作成と公開の手順は `.codex/skills/` にあります。技術記事は公式の一次情報を確認して執筆し、公開 API の実行は明示的に依頼された場合だけ行います。

## 開発

```bash
# プレビューサーバー起動
npm run dev

# 新規記事作成
npm run new:article

# リントチェック
npm run lint
```
